# 广告投产比偏低排查

本文是 AdOps Support Copilot 的模拟内部 SOP，不代表任何真实广告平台或公司的官方规则。

## 适用范围

适用于用户询问 ROAS、投产比低、投入产出或广告是否亏损，以及计划命中 ROAS 偏低异常的场景。

## 排查步骤

1. 确认消耗达到已确认的最小样本。
2. 确认转化收入和广告消耗的统计日期。
3. 检查转化量和 CVR 是否偏低。
4. 检查 CPA 是否偏高。
5. 检查转化收入是否低于其他计划或日期。
6. 对比同一广告主其他计划的 ROAS。
7. 结合商品成本等系统外信息，由运营人员判断真实盈利情况。

## 可能原因

转化量不足、转化收入偏低、广告消耗增长快于转化收入，或者转化回传和收入归因数据不完整，都可能导致 ROAS 偏低。

## 回答边界

ROAS 只反映转化收入与广告消耗的比率。项目没有商品成本、履约成本和人工成本，不能计算净 ROI。ROAS 偏低不等于已经证明业务亏损。
