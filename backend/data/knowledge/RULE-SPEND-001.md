# 广告消耗异常波动排查

本文是 AdOps Support Copilot 的模拟内部 SOP，不代表任何真实广告平台或公司的官方规则。

## 适用范围

适用于用户询问某天消耗、花费为什么突然上升或下降，以及计划命中单日消耗异常波动的场景。

## 排查步骤

1. 确认分析对象是单日数据。
2. 确认前 7 天有效数据和平均日消耗满足已确认的最小样本。
3. 计算当日消耗相对前 7 天平均值的倍数。
4. 检查曝光量和点击量是否同步变化。
5. 人工检查计划状态和预算是否变化。
6. 人工检查素材、定向或审核状态是否变化。
7. 结合 CTR、CVR、CPA 和 ROAS 判断波动是否伴随效果变化。

## 可能原因

预算或计划状态变化、曝光量和点击量变化、素材定向或审核状态变化，以及外部流量环境变化，都可能导致消耗波动。

## 回答边界

系统没有预算修改历史、素材版本、定向变更和审核日志，只能确认消耗和已有投放指标的变化。消耗上升不一定是坏事，消耗下降也不一定表示损失，必须结合转化和 ROAS 分析。
