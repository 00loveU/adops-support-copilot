# 广告投放指标口径说明

本文是 AdOps Support Copilot 的模拟内部 SOP，不代表任何真实广告平台或公司的官方口径。

## 原始指标

曝光量是广告被展示的次数。点击量是广告被点击的次数。转化量是完成模拟目标行为的次数。广告消耗是投放产生的模拟费用。转化收入是归因到广告的模拟收入。

## 计算指标

CTR 等于点击量除以曝光量，用于观察曝光转化为点击的比例。CVR 等于转化量除以点击量，用于观察点击转化为目标行为的比例。CPC 等于广告消耗除以点击量。CPA 等于广告消耗除以转化量。ROAS 等于转化收入除以广告消耗。

## 计算边界

多日查询需要先汇总曝光、点击、转化、消耗和收入，再根据汇总结果计算比率，不能使用每日比率的简单平均值。分母为 0 时，相应指标不可计算，系统应说明原因。

ROAS 是广告投产比，不等于净 ROI。项目没有商品成本、履约成本和人工成本，不能根据 ROAS 直接判断真实利润。

## 使用提醒

指标高低需要结合统计日期、样本量和业务目标理解。系统只使用已确认的模拟阈值判断异常，不将这些阈值描述为真实平台标准。
