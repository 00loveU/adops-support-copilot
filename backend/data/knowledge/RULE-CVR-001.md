# 转化率异常排查

本文是 AdOps Support Copilot 的模拟内部 SOP，不代表任何真实广告平台或公司的官方规则。

## 适用范围

适用于用户询问 CVR 偏低、有点击但没有转化，以及计划命中低 CVR 或有点击无转化异常的场景。

## 排查步骤

1. 确认点击量是否达到已确认的最小样本。
2. 确认转化量和 CVR 的统计日期。
3. 区分“完全无转化”和“存在转化但 CVR 偏低”。
4. 对比同一计划其他日期的 CVR。
5. 人工检查落地页是否可访问、加载是否正常。
6. 人工检查广告内容与落地页或商品是否一致。
7. 人工检查商品价格、库存和转化路径。
8. 人工检查转化回传是否正常。

## 可能原因

落地页体验或可用性问题、广告承诺与商品信息不一致、价格库存或购买路径问题，以及转化回传没有正确记录，都可能造成转化率异常。

## 回答边界

系统没有落地页监控、商品数据和转化回传日志，不能直接确认具体原因。转化量为 0 时，CPA 不可计算。命中“有点击无转化”后不重复报告“CVR 偏低”。
