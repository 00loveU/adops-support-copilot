# 广告计划无曝光排查

本文是 AdOps Support Copilot 的模拟内部 SOP，不代表任何真实广告平台或公司的官方规则。

## 适用范围

适用于用户询问广告计划没有曝光、没有展现、没有启动或投放不出去，以及启用计划命中无曝光异常的场景。

## 排查步骤

1. 确认广告计划编号和查询日期。
2. 确认计划状态是否为 active。
3. 确认查询范围内曝光量是否确实为 0。
4. 人工检查计划是否处于有效投放日期。
5. 人工检查预算和余额是否满足投放条件。
6. 人工检查审核状态。
7. 人工检查定向和投放条件是否过窄。

## 当前系统可以确认的事实

系统只能确认计划状态、查询日期，以及曝光量、点击量和消耗。计划状态不是 active 时，不能命中“启用计划无曝光”。

## 可能原因和回答边界

计划未通过审核、预算或余额不足、投放日期不匹配、定向范围过窄都可能造成无曝光。但是当前模拟数据不包含真实审核结果、账户余额、定向范围和平台流量分配信息，因此这些内容只能作为人工排查方向，不能作为已经确认的原因。
