# 转化成本偏高排查

本文是 AdOps Support Copilot 的模拟内部 SOP，不代表任何真实广告平台或公司的官方规则。

## 适用范围

适用于用户询问 CPA、转化成本或获客成本偏高，以及计划命中 CPA 偏高异常的场景。

## 排查步骤

1. 确认转化量达到已确认的最小样本，避免少量转化导致指标剧烈波动。
2. 确认 CPA 的统计日期和计算口径。
3. 同时检查 CPC 和 CVR。
4. CPC 偏高时，继续检查流量成本和素材点击表现。
5. CVR 偏低时，按照转化率异常 SOP 排查。
6. 对比同一广告主其他计划的 CPA。
7. 由运营人员判断模拟阈值是否符合具体业务目标。

## 可能原因

点击成本偏高、转化率偏低、当前转化样本不足，或者不同计划的目标和商品价值不同，都可能影响 CPA。

## 回答边界

系统只按已确认的模拟阈值判断异常，不知道广告主真实目标 CPA，不能声称高于模拟阈值就一定亏损。转化量为 0 时不判断 CPA 偏高，只说明 CPA 不可计算。
